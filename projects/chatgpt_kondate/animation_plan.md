# 冷蔵庫の写真でChatGPTに夕飯を考えてもらう：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - ナレーションはユーザーの原稿どおり。670 文字なので3パートに分けて生成した（intro〜choose / problem〜conditions / tips〜cta）。各パート2テイク。
  - Scribe で両テイクとも誤読なし（「ChatGPT／チャットジーピーティー」「夕飯／ゆうはん」「三つ／みっつ」「二十分／にじゅっぷん」「生姜焼き」「嫌／いや」「一品／いっぴん」「辛く／からく」「量／りょう」は表記の違いだけ）。
  - 全体が 0.5 秒短く、「写真を添付して、」の読点の間が自然な take2 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: Scribe の文字タイムスタンプを台本に対応付けた（463/465 文字）。全長 71.77 秒 / 2153 フレーム（30fps）。
- 構成: `remotion-composer/src/chatkondate`（Remotion + @remotion/three）。台所のセット・人形・食材・スマホ・メニューカードは `src/kondate`（「なんでもいい」はAIで解決）から使う。新しい画面（ChatGPT とのチャット）、料理（生姜焼き・焼き魚）、マグカップはこのフォルダに作る。毎フレームの絵はフレーム番号だけで決まる。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夜7時の台所のミニチュア**、1つのセットだけで通す（前作と同じ家）。
  - 冷蔵庫（左奥）、カウンター、群青の夜の窓、手前に小さなダイニングテーブル。
  - 説明のカット（スマホ・チャット・メニュー）は、台所の手前にスマホとカードを浮かべ、奥の台所を被写界深度で暖色のぼけにする。
  - カメラは前作で数値で合わせた型（`HOOK_CAM` / `HERO_CAM` / `FRIDGE_CAM` / `TABLE_CAM`）を使い、新しい配置は投影計算で確かめる。
- 人物: 顔のない木製の人形。親＝生成りのカーディガンにからし色のエプロン、子ども＝オレンジのTシャツ。
- 色の意味を固定する。
  - シアン（帯色）＝ChatGPT（AI）。小さな多面体のコアとスマホの光。
  - オレンジ＝子どもの声・子どもが選んだもの。
  - ティール＝条件が伝わった・できる（✓）。赤＝断られた・家にない（✕）。
- 光: 天井のペンダントの暖色スポットがキー。冷蔵庫を開けると中から白い光。補助光は弱め。最後のカットだけペンダントを落として夜の静けさにする。
- 素材: 人形は木目、床はフローリング、冷蔵庫はクリーム色の塗装。スマホの画面とメニューカードはキャンバステクスチャ。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインを連発しない。カードとチップは「ポン」と少し行き過ぎて止まる。
- 後処理: 被写界深度 → ブルーム（ペンダント・冷蔵庫・AI だけ）→ ビネット → ACES。場面転換は暖色の光のディップ。シャッターは白いフラッシュ。
- シリーズ帯: RGB(128,242,255)、黒文字で「親のための AIライフハック」。2段目に場面ごとのトピック。
- **AI 制作の注記は入れない**（ユーザー指定）。
