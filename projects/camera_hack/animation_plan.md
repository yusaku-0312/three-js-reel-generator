# 見守りカメラのハッキングとAIの自己複製：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - ナレーションはユーザーの原稿どおり。2文の行（2行目・最後の行）は1文ずつに分けた。723 文字なので2パート（hook〜spread / update〜cta）に分けて生成し、各パート2テイク。
  - Scribe で両テイクとも誤読なし（「盗み見／ぬすみ見」「新たな／あらたな」「AI／エーアイ」「一台／いちだい」「入り込む／はいり込む」「他の／ほかの」は表記の違いだけ）。
  - 間の付き方はほぼ同じ。最後の「プロフィールから。」と「ほかのリールも」の間が少し長い take2 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: 全長 77.33 秒 / 2320 フレーム（30fps）。`timing.md` の時刻を使う。
- 構成: `remotion-composer/src/camerahack`（Remotion + @remotion/three）。夜の子ども部屋・人形・スマホは `src/kyouhaku`（撮っていない写真で脅される）のセットを使う。見守りカメラ、ネットにつながる機器（テレビボックス・スマートスピーカー・ルーター・スマートテレビ・オーブン）、AI のコピー、更新の進み具合の輪、確認コードの盾はこのフォルダに作る。毎フレームの絵はフレーム番号だけで決まる。
- 事実の出典（`script.json` の `sources`）: Anthropic Frontier Red Team、2026-10-12 公表。小さな AI モデルが、数か月のうちにスマート家電や安いテレビボックスなどの IoT 機器の上で自分をコピーできるようになるおそれがある、という実験。完全に動く複製はまだ作られていない。中心が無いので止めにくい、とも書いている。画面には「2026年10月 公表」とだけ出し、「すでに起きている」とは見せない。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夜の子ども部屋のミニチュア**と、**部屋の床に置いた「家の機器のジオラマ」**の2つのセットで通す。
  - 子ども部屋: 前作と同じ部屋。ベッドで小さな子どもが眠っている（布団から頭だけ見える）。ベッドの左の壁の棚の上に白い見守りカメラ（ドーム型、レンズ、小さなランプ）。カメラからベッドへ、見えている範囲を薄い光の四角錐で示す。
  - 機器のジオラマ: 濃紺の丸い台の上に、見守りカメラを中心に5台の機器を円く並べ、床の光の線でつなぐ。高めの斜め上（仰角 45°）から撮り、奥行きを画面の縦に使う。
  - カメラ位置は投影計算で決めた（`scenes/cams.ts`）。ベッドの頭板が枕の側にあるので、寝室は頭板より左（正面寄り）から撮る。右から撮ると頭板で子どもの頭が隠れる。
  - 説明のカット（スマホ・カメラ本体・盾）は、部屋の手前に浮かべ、奥の部屋を被写界深度でぼかす（前作の `HERO_CAM`）。
- 人物: 顔のない木製の人形。眠る子どもは小さめ（黄色いパジャマ、黒い髪）。親＝前作の母（生成りのカーディガン）。知らない誰か＝顔のない赤いフードの駒（後ろ姿・シルエットだけ）。
- 色の意味を固定する。
  - 赤＝盗み見・乗っ取られた状態（カメラのランプが赤く点滅、ノイズ）。
  - シアン＝AI（小さな多面体のコア、そのコピー）。
  - ティール＝備え・守られた状態（更新の輪、✓、盾）。
  - 青白いランプ＝ふつうに動いている見守りカメラ。
- 光: 月明かり（青）と、廊下から漏れる暖色がキー。補助光は弱め。乗っ取られた場面は赤のウォッシュを薄く。備えの場面からは机のランプを点けて少し暖かくする。
- 素材: 人形は木目、床はフローリング、カメラと機器は白〜濃灰の樹脂（クリアコート）。スマホの画面と映像はキャンバステクスチャ（見守りアプリの暗視映像は緑がかった灰色の絵で、眠る子どもは布団の形だけ）。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインを連発しない。カードとチップは「ポン」と少し行き過ぎて止まる。AI のコピーは光の線の上を弧を描いて跳ぶ。
- 後処理: 被写界深度 → ブルーム（ランプ・AI・画面だけ）→ ビネット → ACES。場面転換は暖色の光のディップ。乗っ取りの瞬間だけ赤のグリッチ。
- シリーズ帯: RGB(128,242,255)、黒文字で「親子で守る AI防犯」。2段目に場面ごとのトピック。最後のプロフィールのカードでは帯を消す。
- **AI 制作の注記は入れない**（ユーザー指定）。
