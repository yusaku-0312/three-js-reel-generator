# ミルクティーとティーラテの違い：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 2パートに分けて生成した（hook+latte+milk / tealatte+ratio+taste+outro）。パート1は2テイク、パート2は1テイク（2本目のダウンロードが同じファイルだった）。
  - Scribe で全テイク誤読なし（「何／なに」「牛乳／ぎゅうにゅう」「入れた／いれた」「濃く／こく」「泡／あわ」などは表記の違いだけ）。
  - 間の長さはほぼ同じなので take1 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: Scribe の文字タイムスタンプを台本に対応付け、チャンクの開始を声の立ち上がりに合わせた。全長 35.85 秒 / 1076 フレーム（30fps）。
- 構成: `remotion-composer/src/milktealatte`（Remotion + @remotion/three）。カフェのカウンター・カップ・ポット・ピッチャー・液面シェーダー・注ぐ流れは `src/royalmilk` から、湯気・きらめき・香りの帯・後処理は `src/golden2` と `src/paradise` から使う。ラテグラス（層が見える耐熱グラス）、スチームノズル、ミルクの泡、牛乳びん、イタリアの旗は `src/milktealatte/three` に作る。毎フレームの絵はフレーム番号だけで決まる。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夕方のカフェのカウンター**（紅茶の雑学シリーズと同じセット）。1つのセットで通す。
  - 主役は2つ。左手前＝白磁のカップのミルクティー、右奥＝取っ手付きの透明な耐熱グラスのティーラテ（下から紅茶 → ミルク → 白い泡の層が見える）。9:16 は横が狭いので奥行きをずらす。
  - カップは「低くて丸い」、グラスは「背が高くて層が見える」。形だけで2つが区別できるようにする。
- 色の意味を固定する。
  - 琥珀＝紅茶、白＝牛乳・泡、銀＝スチーム。
  - ミルクティーのラベルは琥珀色（#f0a04b）、ティーラテのラベルはクリーム地にこげ茶の文字（泡のアイコン）。
- 光: キーは左上の暖色スポット、リムは右奥から暖色（グラスの縁と泡のハイライト）。補助光は弱め（半球光 0.42 / 正面 0.45）。
- 素材: カップは白磁＋金の縁。グラスは加算のフレネル（`fresnelGlass`）で、中の層は円柱を重ねる（紅茶はこげ茶＋弱い自己発光、ミルク層はキャラメル、泡は少し粗いマットな白のドーム）。ピッチャーはステンレス、スチームノズルは細い銀の管。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインは各場面で最大1回。液面はゆっくり回る。泡はふわっと盛り上がる。
- 後処理: 被写界深度 → ブルーム（しきい値 1.0、湯気・グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。
