# 紅茶とクッキーが合う理由：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 3パートに分けて生成（hook+tannin+shibumi / aroma+result / outro）、各2テイク。
  - Scribe で全テイク誤読なし（「単に／たんに」「油っぽさ／あぶらっぽさ」「浸す／ひたす」「早く／はやく」などは表記の違いだけ）。
  - 行間の間が揃っている take2 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: 全長 75.97 秒 / 2279 フレーム（30fps）。ユーザーの台本どおり（長め）。
- 構成: `remotion-composer/src/cookietea`。カフェのカウンター（`royalmilk` の Stage）、白磁のカップ（`golden2` の Cup）、湯気・香りの帯・グロー・きらめき（`paradise`）を使う。クッキー（かじり跡・浸した部分が濃くなる）、皿、バター、油の粒、イギリスの旗は `src/cookietea/three` に作る。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夕方のカフェのカウンター**（紅茶の雑学シリーズと同じセット）。左手前＝白磁のカップの紅茶、右奥＝白い皿にバタークッキー3枚。9:16 なので奥行きをずらして縦に重ねる。
- 色の意味を固定する: 琥珀＝紅茶・渋み・香り、金色の粒＝バターの油分、きつね色＝クッキー、濃い茶色＝紅茶を吸ったクッキー。
- 光: キーは左上の暖色スポット、リムは右奥から暖色。補助光は弱め（半球光 0.42 / 正面 0.45）。
- 素材: クッキーは押し出した円盤（面取り）＋キャンバステクスチャ（中心が明るく縁が焼き色、穴と砂糖のつぶ）。浸した部分は暗く少しつやを出す。油の粒は金色のクリアコート球（影を落とさない）。皿はオフホワイト #e9e4da。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインは各場面で最大1回。クッキーは「持ち上がる → 傾く → 沈む」だけで、手は出さない。
- 後処理: 被写界深度 → ブルーム（しきい値 1.0、湯気・グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。最後まで出したまま（tea パターン）。
