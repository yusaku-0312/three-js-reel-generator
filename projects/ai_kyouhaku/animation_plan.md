# 撮っていない写真で脅される：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 4パートに分けて生成した（hook+fake+fear / intro+rule1 / rule2+rule3 / rule4+outro）。各パート2テイク。
  - part1 は 2行目「お子さんの顔が写った性的な画像」が ElevenLabs の利用規約チェックで止められた。ユーザーの選択で「お子さんの顔が写った、人には見せられないような画像」に言い換えた（音声・字幕とも）。
  - `join_parts.py` で 0.85 秒の間を入れてつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速にした。採用は take1（全パートのテイク1、90.4 秒）。
- 読みの確認: Scribe で両テイクとも誤読なし（「脅／おど」「SNS／エスエヌエス」「一人／ひとり」「真偽／しんぎ」などは表記の違いだけ）。
- タイミング: 全長 93.65 秒 / 2810 フレーム（30fps）。最後の声は 90.65 秒。そのあと 3 秒、言葉のメモカードを見せて終わる。読み上げなしの締めのテロップのカットは入れない（ユーザー指定 2026-10-24、カットごと削除）。AI 制作の注記も入れない（ユーザー指定）。
- 構成: `remotion-composer/src/kyouhaku`（`src/kondate` の型を流用）。毎フレームの絵はフレーム番号だけで決まる。

## 描かないもの（このテーマの約束）
- **偽の画像そのものは一度も描かない。** 画面に出るのは「グレーのモザイク＋⚠マーク＋『非表示』」のカードだけ。肌色も使わない。
- 人物は顔のない木製の人形。実在の子どもは描かない。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: 1つのセット「夜の子ども部屋」のジオラマ。奥の壁（z −3.2）に夜の窓、左に机とデスクライト、右にベッド、左の壁にドア（開くと廊下の暖かい光）。
  - 説明のカットは、部屋の手前にスマホやカードを浮かべ（HERO_CAM、部屋は大きくぼかす）、別のセットは作らない。
  - 9:16 の画角はカメラ位置を計算で合わせる（主役は x 140–940 / y 490–1420）。
- 人物:
  - 子ども: 中高生に見える背丈（1.3）、紺のパーカー、黒髪。スマホを持つ。
  - ママ: 生成りのカーディガン。パパ: グレーのセーター。
- 色の意味:
  - 赤＝脅し（知らないアカウント、脅しのメッセージ）。シアンのノイズ＝AI で作った偽物。ティール＝安全・相談・守る。オレンジの暖色＝家族の明かり。
- 光:
  - 夜の部屋。青い月明かり（窓）＋スマホの画面光。
  - 怖さの場面はデスクライトを消し、スマホの光だけにする。
  - 相談してからは、ドアの向こうの暖かい光とデスクライトが戻る。
  - 補助光は弱め（半球光 0.4 / 正面 0.5）。
- 素材: 人形は木目＋クリアコート、布はマット。スマホはガラス面とキャンバステクスチャの画面（DM・設定画面）。カードは厚みのある角丸。
- 動き:
  - カメラはドリー・トラック・クレーンだけ。ズームインを連発しない。
  - スマホは脅しのときだけ小刻みに震える。
  - 物は大きく上下に動かさず（字幕帯を横切らない）、その場でスケールインする。
- 後処理: 被写界深度 → ブルーム（画面・ランプ・グローだけ）→ ビネット → ACES。
  - 転換は光のディップ（暖色）。
  - 偽画像を作る場面だけ、RGB ずれのグリッチ。脅しのメッセージの場面は赤い危険の色を少し乗せる。
- シリーズ帯: RGB(128,242,255)、黒文字で「親子で守る AI防犯」。2段目は場面のトピック。
- 音: 静かなピアノの BGM（ElevenLabs sound-generation）。バイブ、通知音、グリッチ、硬貨、シャッター、ポップ、ドア。

- 主役とテロップは x 140–940 / y 490–1420 に収める。
