# CHAGEE（覇王茶姫）ってどんなお店？：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 2パートに分けて生成（hook+wonyoung+menu / size+korea+japan+outro）、各2テイク。
  - Scribe で誤読なし。全体の文字起こしでは「1月」「4月」「2時間」の数字が落ちるが、切り出して再確認すると take2 は「1月」「四月」「二時間」と読めている（Scribe が短い数字を落とすだけ）。
  - take2 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: 全長 53.73 秒 / 1612 フレーム（30fps）。30秒以上の条件を満たす。
- 構成: `remotion-composer/src/chagee`。シェル（カフェのバンド・字幕・ディップ）とカウンターのセットは `src/milktealatte` / `src/royalmilk` から。新しく作るもの（`src/chagee/three`）: 青花（藍と白）の柄のテイクアウトカップ、透明カップのジャスミンミルクティー（`LatteGlass` を泡なしで流用）、ジャスミンの花、茶葉の入った抽出バスケット、テーブルに置いた絵地図（world-atlas + d3-geo をキャンバスに描く）と地図のピン。ユーザーの写真（ウォニョン）は `public/chagee/wonyoung.webp` を2D のフォトカードとスマホ画面に入れる。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夕方のカフェのカウンター**（紅茶の雑学シリーズと同じセット）。後半はカウンターに置いた **太平洋中心の絵地図**（中国・東南アジア・韓国・日本・アメリカ西海岸が1枚に入る）。
  - 冒頭は左上にユーザーの写真（フォトカード、少し傾ける）、右下に3Dの青花カップ。写真は画面の一部（幅 約440 px）。
- 色の意味を固定する。
  - 藍（#1f4fa8）＝CHAGEE（カップの柄・チップの縁・ピン）、白＝牛乳、淡い金緑＝ジャスミン茶、赤＝LIVE、灰色の点線＝日本（お店なし）。
- 光: キーは左上の暖色スポット、リムは右奥。補助光は弱め（シリーズの既定値）。地図のシーンは少しだけ明るく（key 3.4）。
- 素材: 青花カップは白い紙の質感（roughness 0.6）にキャンバスで描いた藍の唐草・花模様の帯と、白い丸いふた。地図は生成りの紙に、海は淡い水色、陸はベージュ、中国は少し濃い色。ピンは藍の球＋銀の針、日本だけ点線の輪と「？」。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインは各場面で最大1回。ピンは上から落ちて、着地で小さく弾む。
- 後処理: 被写界深度 → ブルーム（グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。
- 写真について: ウォニョン本人の写真はユーザーの添付画像そのまま（加工は角丸と枠だけ）。顔の上に文字を重ねない。

## デッドゾーン
- シリーズ帯は y 276–472、字幕は y 1450 から幅 800 px（x 140–940）。
- 主役とテロップは x 140–940 / y 490–1420 に収める。0秒から絵が動く（フェードインしない）。
- AI 制作の注記は入れない。プロフィール導線のカードは使わない（tea パターン）。
