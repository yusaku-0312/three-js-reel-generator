## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: カウンターの上に置いた**ミニチュアの部屋**。いちばん伝えたい「テーブルの高さ」を、2つのテーブルを並べて見せる。
  - 左手前＝低いテーブル（ソファの前のローテーブル、3段のスタンドとカップ）＝アフタヌーンティー。
  - 右奥＝高い食卓（脚の長いダイニングテーブル、椅子、パイ・パン・ポット）＝ハイティー。
  - 9:16 は横が狭いので、2つは奥行きをずらして置く。高さの違いは、右のテーブルの横に伸びる金色の高さの矢印で見せる。
  - 日本のホテルの場面は、同じ部屋を夜にして（暖色の明かりを落とし、奥に夜景のぼけ）、高いテーブルに3段のスタンド・ローストビーフ・シャンパングラスを並べる。
- 色の意味を固定する: 淡いピンク（#f4a6b8）＝アフタヌーンティー（おやつ）、琥珀（#f0a04b）＝ハイティー（晩ごはん）、赤い✕＝「違う」、金＝高さ。
- 光: royalmilk の DEFAULT_LIGHTING（左上の暖色スポット、右奥の暖色リム、補助光は弱め）。夜の場面はスポットを弱め、奥のぼけを増やす。
- 素材: テーブルはくるみ材、ソファはえんじのベルベット（つや消し）、スタンドは金の支柱と白磁の皿、パイはこんがりした焼き色、チーズトーストは黄色いチーズ、ローストビーフはピンクの断面、シャンパングラスは淡い金の液体に小さな泡。
- 動き: カメラはドリー・トラック・クレーンだけで減速カーブ。料理はポンと拡大して現れる（下からせり上げない）。
- 後処理: 被写界深度 → ブルーム → ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。最後まで出したまま（tea パターン）。最後はまとめのカードで終える（プロフィール導線なし）。
- お酒が出るので、10行目の間だけ画面に小さく「※お酒は20歳から」を出す（キャプションにも書く）。
