# AIの声で「迎えに来たよ」：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 長文で精度が落ちないよう、6パートに分けて生成した（hook+ai+story / reveal+promise / p1 / p2 / p3 / outro）。各パート2テイク。
  - 採用: part1〜4 はテイク1、part5・6 はテイク2（Scribe がセリフ部分をカギカッコとして聞き取っており、セリフらしく読めている）。
  - `join_parts.py` で、各パートの頭と尻の無音を詰め、0.85 秒の間（テイク内の行間と同じ）でつないだ（take3）。v4 の画面に速度設定が無いため、ffmpeg `atempo=1.2` で 1.2 倍速にした（音程は変えない）。
- 読みの確認: Scribe で全文を確認し、誤読はなかった（「AI／エーアイ」「合言葉／あいことば」「時／とき」「三つ／みっつ」は表記の違いだけ）。
- タイミング: Scribe の文字タイムスタンプを台本に対応付けた（866/866 文字）。全長 141.07 秒 / 4232 フレーム（30fps）。
- 構成: `remotion-composer/src/aimukae`（Remotion + @remotion/three）。毎フレームの絵はフレーム番号だけで決まる。3D は全て手続き生成。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 世界観: **夕方の通学路のミニチュア・ジオラマ**と、**夜の青い「声の研究室」**の2つのセット。
  - 町: 歩道とガードレール、横断歩道、街灯、家並み、学校、お店、子ども110番の家、止まっているワゴン車。チルトシフト（被写界深度を浅く）で「模型の町」に見せる。
  - 研究室: 濃紺の無限背景に、スマホと声の波形だけを置く。AI の仕組みや約束の説明はこちらで見せる。
- 人物は**顔のない木製の人形**（フィギュア）にする。実在の子どもを描かず、怖さを和らげるため。
  - 子ども: 黄色い通学帽と赤いランドセル（小学生だとすぐ分かる）。
  - 知らない男: 背が高く、濃いグレーのパーカーにキャップ。
  - ママ: 生成り色のカーディガン（声の色＝ピンク）。
- 色の意味を固定する。
  - ピンク＝ママの声。偽物の声は、同じピンクに**シアンのノイズのフチ**がつく。
  - 赤＝危険（偽物、知らない男のスマホ）。ティール＝安全（約束、子どもの携帯、助けを求める場所）。
- 光:
  - 町: 低い夕日のキー（右奥から、長い影）、空色の半球光、家の窓と街灯の暖色の点光源。
  - 研究室: 上からの青いソフトボックスと、波形の自己発光。
  - 補助光は弱めにする（半球光 0.45、正面 0.5）。
- 素材: 人形は木目の粗い MeshPhysical、道路はアスファルトのノイズ、家はマット。スマホはガラス面＋キャンバステクスチャの画面（通話画面、波形、連絡先）。
- 動き:
  - カメラはドリー・トラック・クレーンだけで、減速カーブを使う。ズームインを連発しない。
  - 人形は小さく跳ねながら歩く（おもちゃらしく）。
  - 波形は声の時刻に合わせて揺れる。
- 後処理: 被写界深度（ジオラマ感）→ ブルーム（街灯・窓・波形だけ）→ ビネット → ACES。
  - 場面転換は「光のディップ」。研究室に入るときは青、町に戻るときは夕日色。
  - 偽物が明かされる瞬間だけ、彩度を落とし、RGB ずれのグリッチを入れる。
- シリーズ帯: アカウントの帯色 RGB(128,242,255)、黒文字で「親子で守る AI防犯」。2段目に場面ごとのトピックを出す。
