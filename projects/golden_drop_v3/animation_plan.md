## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: 主役は常に「ポットの口の一滴」か「それを受けるカップ」。一滴は画面の中央より少し上、カップは中央下に置き、y 490–1420 の中に収める。
- 光: 夜のティールーム。暗い木のテーブルに、真上からの暖色スポットを1灯。ゴールデンドロップだけが自分で光り（自己発光＋点光源）、画面でいちばん明るい点になる。
- 素材: 金縁の白磁（クリアコート）、耐熱ガラス、透過する琥珀色の紅茶。急須は朱泥（赤茶の素焼きに薄いつや）、湯呑みは生成りの釉薬、緑茶は黄緑。
- 動き: カメラは減速カーブのドリーと短い弧だけ。しずくは「ためる → ふくらむ → ちぎれる → 落ちる → 王冠しぶき」の順で、着水後はスローモーション。
- 後処理: 被写界深度（しずくにピント）→ ブルーム（しずくと光るカップだけ）→ ACES。場面転換は金色のディップ（明るくなって切り替わる）。
