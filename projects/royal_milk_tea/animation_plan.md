# ロイヤルミルクティーとミルクティーの違い：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 2パートに分けて生成した（hook+milk+royal / origin+tip+outro）。各パート2テイク。
  - Scribe で両テイクとも誤読なし（「全く／まったく」「別物／べつもの」「茶葉／ちゃば」「1965年頃」「美味しく／おいしく」は表記の違いだけ）。
  - 冒頭のフックの間が詰まっていて、全体が 0.25 秒短い take1 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: Scribe の文字タイムスタンプを台本に対応付けた（285/286 文字）。全長 45.47 秒 / 1364 フレーム（30fps）。
- 構成: `remotion-composer/src/royalmilk`（Remotion + @remotion/three）。カップ・ポット・湯気・きらめき・後処理は `src/golden2` と `src/paradise` から使い、手鍋・コンロ・ミルクピッチャー・ミルクの液面・メニュー看板は `src/royalmilk/three` に作る。毎フレームの絵はフレーム番号だけで決まる。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夕方のカフェのキッチンカウンター**、1つのセットで通す。
  - 手前にくるみ材のカウンター。奥にクリーム色のタイルの壁と、暖色の店の明かり（被写界深度で丸いぼけ）。
  - 主役は2つのカップ。左＝ミルクティー（琥珀にミルクが混ざった明るいキャラメル色）、右＝ロイヤルミルクティー（とろりとした濃いクリーム色）。9:16 は横が狭いので、2つは奥行きをずらして置く。
  - 作り方の場面は、カウンターの上のコンロと手鍋に寄る（同じセットの中）。
- 色の意味を固定する。
  - 琥珀＝紅茶、白＝牛乳。
  - ミルクティーのラベルは琥珀色（#f0a04b）、ロイヤルミルクティーのラベルは紺に金の文字（王冠のアイコン）。
  - 赤い✕＝「ない」、ティール＝コツ。
- 光:
  - キー: 左上の暖色スポット（カップに斜めの影）。
  - リム: 右奥から暖色。液面のハイライトを出す。
  - 補助光は弱め（半球光 0.42 / 環境 0.45）。コンロの青い炎は自己発光で小さく。
- 素材: カップは白磁＋金の縁（golden2 の Cup）。液面は自前の材質で、紅茶の琥珀からミルクの渦が広がり、混ざりきるとキャラメル色になる（シェーダーで `milk` と `swirl` を制御）。手鍋はホーロー（クリーム色、縁は黒）。茶葉は小さな濃い茶色の薄片。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインは各シーン最大1回。注ぐ液体の流れは管状、液面はゆっくり回る。
- 後処理: 被写界深度 → ブルーム（しきい値 1.0、炎・グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 紅茶の雑学シリーズと同じ「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。
