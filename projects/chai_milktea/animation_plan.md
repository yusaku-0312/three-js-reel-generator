## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: `royalmilk` と同じ**夕方のカフェのキッチンカウンター**を1つのセットで通す。
  - 主役は2つの器。左手前＝ミルクティー（白磁のカップ、キャラメル色）、右奥＝チャイ（素焼きのクルハド、オレンジがかった濃い茶色に小さなスパイスの粒）。9:16 は横が狭いので奥行きをずらす。
  - 作り方の場面は、カウンターの上のコンロと手鍋に寄る。言葉の由来は、カウンターに広げた紙の地図（中国・ペルシャ・インド・日本）。
- 色の意味を固定する: 琥珀（#f0a04b）＝ミルクティー、テラコッタ（#e07a3c）＝チャイ、白＝牛乳、赤い✕＝「違う」、ティール＝手順の番号。
- 光: royalmilk の DEFAULT_LIGHTING（左上の暖色スポット、右奥の暖色リム、補助光は弱め）。地図の場面はスポットを地図の中心へ。
- 素材: クルハドは素焼き（つや消しのテラコッタ、縁だけ少し濃い）。CTC は小さな丸い粒（濃い茶色、少しだけ照り）。スパイス: しょうが（薄い輪切り、淡い黄）、カルダモン（緑の小さなさや）、シナモン（巻いた茶色の棒）、八角（星形）。
- 動き: カメラはドリー・トラック・クレーンだけで減速カーブ。ズームインは各シーン最大1回。注ぎは管状、液面はゆっくり回る。
- 後処理: 被写界深度 → ブルーム（しきい値 1.0、炎・グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。最後まで出したまま（tea パターン）。最後はまとめのカードで終える（プロフィール導線なし）。
