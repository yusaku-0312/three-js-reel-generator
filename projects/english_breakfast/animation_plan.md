# イギリスで一番人気の紅茶（イングリッシュブレックファスト）：Three.js アニメーション計画（ナレーション1行ずつ）

- 台本: ユーザーの原稿をそのまま使用（tea パターン）。数字は読ませる文で「にせんにじゅうねん」「ごじゅうよんパーセント」「じゅうはちパーセント」「はちじゅうごパーセント」と指定。
- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、安定性 50%、各行の頭に `[narrative]`。
  - 3パートに分けて生成（hook〜why / blend〜milk / breakfast〜outro）。アカウントは3つ目のアカウント（元のアカウント2つはクレジット切れ）。
  - Scribe の API キーのアカウントがクレジット切れだったので、文字起こしは whisper.cpp（large-v3-turbo）で代用（`scripts/narration_reel/stt_whisper.py`）。両テイクとも誤読なし。take1 は「風味**な**特徴」と聞き取られたので、take2 を採用（「セーロン」は「セイロン」の発音の範囲）。
  - `join_parts.py` でつなぎ、`atempo=1.2`。`spelling` で 2020→二千二十、54%→ごじゅうよんパーセント など読ませる文に戻して 477/477 字が対応。
- タイミング: `timing.md`。全長 72.30 秒 / 2169 フレーム（30fps）。
- 構成: `remotion-composer/src/englishbreakfast`。カフェのカウンター（`royalmilk` の Stage）。新しく作るのは、名前入りの紅茶缶 `three/tins.tsx`（Tin：色と英字ラベルを指定）、茶葉が左右の皿から中央の皿へ飛んで混ざる `three/blend.tsx`（FlyingLeaves）、朝食の皿 `three/breakfast.tsx`（Toast・FriedEgg）、カード類 `labels.tsx`（調査の棒グラフ PollCard・85% の輪 RingStat・最後の問いのカード AskCard）。茶葉の山は `kurenai` の LeafHeap、ミルクの注ぎとカップの液面は `royalmilk` の Pitcher・PourStream・MilkCup、旗は `royalmilk` の FlagPick。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: カウンターの上に物を奥行きで重ねる（9:16 は横が狭いので、缶は手前と奥に互い違い）。主役は画面の上半分（y 500–950）、カードは下半分（y 980–1400）。
- 色の意味: 濃紺に金＝イングリッシュブレックファスト（主役の缶・グラフの棒）、灰青＝アールグレイ、若草＝ダージリン、赤茶＝アッサム、ミルクの白、朝の黄色＝朝食。
- 光: 朝のカフェ（DEFAULT_LIGHTING をやや明るく）。朝食の場面は暖かい黄色のグロー。
- 素材: 缶は漆塗りの円筒に紙の帯（英字の銘柄名）と金の輪。茶葉はほぼ黒の粒。ミルクティーは淡くならない濃い茶色（#8f5531）＝「紅茶の味わいが残る」。
- 動き: カメラはドリーとクレーンだけで減速カーブ。物はポンと拡大して出る（下からせり上げない）。茶葉は弧を描いて中央の皿へ。
- 後処理: 被写界深度 → ブルーム → ビネット → ACES。場面転換は光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。最後まで出したまま（tea パターン、プロフィール導線なし、AI 制作の注記なし）。最後は問いのカード（まとめ＋「コメントで教えてね」）で終える。
