# パラダイスティー：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`、テイク2を採用。v4 の画面に速度設定が無いため、ffmpeg `atempo=1.1` で 1.1 倍速（音程は変えない）。
- 読みの確認: Scribe で全文一致（「一つ」「香り付け」は表記違いのみ）。
- タイミング: Scribe の文字タイムスタンプを台本に対応付け、無音区間から声の立ち上がりへ寄せた（`build_timeline.py`）。全長 44.5 秒 / 1335 フレーム（30fps）。
- 構成: `remotion-composer/src/paradise`（Remotion + @remotion/three）。毎フレームの絵はフレーム番号だけで決まる。3D は全て手続き生成で、外部モデルは使わない。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 世界観は「楽園の午後のテラス」。日の当たる石のテーブル、ヤシの葉の影、奥に海と空（被写界深度でぼかす）。紅茶の雑学シリーズの夜のティールーム（ゴールデンドロップ）とは対照的に、明るく軽い画面にする。
- 主役は常に、琥珀色のアイスティーのグラス。逆光でいちばん明るく光るのはグラスの紅茶だけ（視覚的階層）。
- 色: 空のターコイズ、紅茶の琥珀、4種の花（青・オレンジ・赤・ピンク）。文字はクリーム色と、サンイエローからコーラルへのグラデーション。
- 光: キーは左奥上からの暖かい太陽のスポットで、ヤシの葉のゴボを通してテーブルに木漏れ影を落とす。フィルは空色と砂色の半球光、リムは右手前の暖色。環境反射には、空のドームと太陽のソフトボックスを PMREM で使う。
- 素材: グラスは縁で強く映り込むフレネルシェル。紅茶はクリップ面で切った半透明の琥珀色で、氷は角の丸い透明キューブ。花びらはベジエ形状を反らせ、両面に描く。
- 動き: カメラは減速カーブのドリーと小さな弧だけを使う。花はつぼみから開き、名前を呼ばれた瞬間に開ききる。花びらは渦を描いてグラスへ吸い込まれる。
- 後処理: 被写界深度（ラックフォーカス）→ ブルーム（しきい値 1.0、太陽と逆光の紅茶だけ）→ 弱いビネット → ACES。場面転換は「日差しのフラッシュ」によるディゾルブだけ。
