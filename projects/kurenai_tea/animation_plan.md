  - 1パート（8行）で2テイク生成。Scribe で両テイクとも「こくちゃ（黒茶）」が「緑茶」と聞き取られた（その部分だけを切り出しても同じ）。

  - 冒頭の間が詰まっている take2 の前後と、新しい行（a）を `join_parts.py` でつないで take3 にした。3つの音量は -18.2 / -18.3 / -17.6 dB でそろっている。ffmpeg `atempo=1.2` で 1.2 倍速。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夕方のカフェのカウンター**を1つのセットとして通す（紅茶の雑学シリーズで共通）。
  - 主役は2つの器。左手前＝こげ茶のマグカップ（中の紅茶が茶色に見える）、右奥＝白磁のカップ（光を通すと紅色）。
  - 9:16 は横が狭いので、2つは奥行きをずらして置く。
  - 茶葉の皿、茶缶、プーアル茶は同じカウンターの別の場所にある。そこへは暖色の光のディップで移る。
- 色の意味を固定する。
  - 茶色（#7a4a2a）＝見た目の印象、紅（#d8321e）＝お茶の本当の色、黒（#2a1a12）＝茶葉。
  - 「紅」の文字・紅色の見本・テアフラビンは同じ紅色。◯＝ティール、✕＝赤。
- 光:
  - キー: 左上の暖色スポット。補助光は弱め（半球光 0.42 / 環境 0.45）。
  - 「光にかざす」場面では、カップの奥から窓の光が差す。液面を見せるためにカメラは斜め上（約20°）から撮るので、窓そのものは画面の外になる。光は、カウンターに落ちたぼけた窓の形の光、真上に近い後ろからのスポット（カウンターの照り返しがカメラに入らない角度）、カップの奥のグローで表す。液面は暗いこげ茶から、透きとおった紅にゴールデンリング（縁の金色の輪）が出る色に変わる。
  - 最初の案（カップの真後ろに立てた明るい窓をほぼ水平から撮る）は、液面が見えず、窓が白く飛んだので変えた。
- 素材:
  - 白いカップは golden2 の白磁＋金の縁。マグは厚手のこげ茶の釉薬で、内側も暗い。
  - 紅茶の液面は自前のシェーダー。`clear`（0＝濁った茶色、1＝透ける紅）と、縁の金色の輪で表す。
  - 茶葉は、よれた黒い粒。発酵の場面の大きな葉は、緑から銅色の赤へ縁から変わる。
- 動き: カメラはドリー・トラック・クレーンだけで、減速カーブ。ズームインは各シーン最大1回。湯気はゆっくり上る。
- 後処理: 被写界深度 → ブルーム（しきい値 1.0、窓・グロー・きらめきだけ）→ ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」（royalmilk と同じカフェ帯）。2段目に場面ごとのトピック。
- AI 制作の注記は入れない。
