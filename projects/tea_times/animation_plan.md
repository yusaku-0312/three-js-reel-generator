# ハイティーとアフタヌーンティーの違い：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 2パートに分けて生成（hook〜afternoon / hightea〜outro）。各パート2テイク。
  - Scribe で両テイクとも誤読なし（「せんはっぴゃくよんじゅうねんごろ／千八百四十年頃」「しょくたく／食卓」などは表記の違いだけ）。
  - take2 を採用（「ソファ」の聞き取りも台本どおり）。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
  - Scribe の漢字表記は `script.json` の `spelling` で**読ませる文（かな）**に戻してから時刻を合わせた（404/404 字が対応）。
  - 「豪華な」は「アフタヌーンティーを」と続けて読まれ 0.3 秒しか出ないので、字幕は「海外のホテルでは豪華な」にまとめた。
- タイミング: `timing.md`。全長 67.69 秒 / 2031 フレーム（30fps）。
- 構成: `remotion-composer/src/teatimes`。部屋・テーブル・ソファ・食卓・料理・夜景は `src/hightea` をそのまま使う（`scenes/set.tsx` から再エクスポート）。新しく作るのは、段ごとに料理が出て光る3段のスタンド `three/stand.tsx`（AfternoonStand）と、メニューのカード・時間の帯（範囲を指定できる TimeBar）・まとめのカード（`labels.tsx`）。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: 前回のハイティー回と同じミニチュアの部屋。左手前の低いテーブル（ソファ・3段のスタンド）＝アフタヌーンティー、右奥の高い食卓（パイ・パン・ポット）＝ハイティー。2つを1枚に入れる引き（WIDE）と、片方に寄るカットを行き来する。
- 色の意味: 淡いピンク（#f4a6b8）＝アフタヌーンティー（夕食の前）、琥珀（#f0a04b）＝ハイティー（夕食そのもの）、金＝見出し・矢印、赤い✕＝「名前より」。
- 光: 昼は dayLight、ホテルの場面（冒頭・海外）は nightLight と奥の夜景のぼけ。
- 素材: スタンドの下段はきゅうりのサンドイッチ（白いパンに緑）、中段はスコーン（焼き色の上面）、上段はピンクと茶色のケーキにクリームといちご。
- 動き: カメラはドリーとクレーンだけで減速カーブ。料理はポンと拡大して出る。食べる順番は、段が下から順に光り、金の矢印が下から上へ伸びる。
- 後処理: 被写界深度 → ブルーム → ビネット → ACES。場面転換は暖色の光のディップ。
- シリーズ帯: 「知ってた？紅茶の雑学」。2段目に場面ごとのトピック。最後まで出したまま（tea パターン）。最後はまとめのカードで終える（プロフィール導線なし、AI 制作の注記なし）。
