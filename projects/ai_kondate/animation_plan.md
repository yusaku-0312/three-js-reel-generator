# 「なんでもいい」はAIで解決：Three.js アニメーション計画（ナレーション1行ずつ）

- 音声: ElevenLabs Web UI、Eleven v4、Otani - Inviting, Clear and Measured、各行の頭に `[narrative]`。
  - 2パートに分けて生成した（hook+intro+step1 / step2〜outro）。各パート2テイク。
  - Scribe で両テイクとも誤読なし（「ごはん／ご飯」「とき／時」「エーアイ／AI」「こんだて／献立」「みっつ／三つ」「さっそく／早速」は表記の違いだけ）。
  - 間の長さはほぼ同じで、全体が1秒短い take1 を採用。`join_parts.py` でつなぎ、ffmpeg `atempo=1.2` で 1.2 倍速。
- タイミング: Scribe の文字タイムスタンプを台本に対応付けた（263/266 文字）。全長 44.61 秒 / 1338 フレーム（30fps）。
- 構成: `remotion-composer/src/kondate`（Remotion + @remotion/three）。後処理・人形・スマホは `src/aimukae/three` を元にし、台所のセットと料理は `src/kondate/three` に作る。毎フレームの絵はフレーム番号だけで決まる。

## アートディレクション（構図 → 光 → 素材 → 動き → 後処理）
- 構図: **夜7時の台所のミニチュア**、1つのセットだけで通す。
  - 奥の壁に冷蔵庫（左）とキッチンカウンター、窓（外は群青の夜）。手前に小さなダイニングテーブル。
  - 説明のカット（スマホ・AI・メニュー）は、台所の手前に物を浮かべ、奥の台所を被写界深度で暖色のぼけにする（研究室のような別セットは作らない）。
  - 9:16 は横が狭いので、親と子は奥行きをずらして立たせる。カメラは `project2` と同じ計算で総当たりして決める。
- 人物: シリーズ共通の**顔のない木製の人形**。
  - 親: 生成り色のカーディガンにからし色のエプロン。
  - 子ども: 家の服（オレンジのTシャツ、紺の半ズボン）、黒い髪。通学帽とランドセルは付けない（家にいる場面なので）。
- 色の意味を固定する。
  - シアン（帯色 RGB 128,242,255）＝AI。AI の光は小さな多面体のコア。
  - オレンジ＝子どもの声・子どもが選んだもの。
  - ティール＝安心（アレルギー・苦手を伝える）。赤い✕＝外すもの（苦手なピーマン）。
- 光:
  - キー: 天井のペンダントライトの暖色スポット（テーブルの上）。
  - 冷蔵庫を開けると、中から白い光が漏れる（ステップ1の見せ場）。
  - 補助光は弱め（半球光 0.4、正面 0.5、環境 0.45）。窓の外の群青で、暖色と寒色の対比を作る。
- 素材: 人形は木目の MeshPhysical、床はフローリング、冷蔵庫はクリーム色のつや消し塗装＋クリアコート、食材はつやのある手続き生成の形（卵・トマト・にんじん・玉ねぎ・鶏肉のパック・牛乳・ピーマン）。スマホの画面はキャンバステクスチャ（カメラ、AI とのチャット、メニュー3つ）。
- 動き:
  - カメラはドリー・トラック・クレーンだけ、減速カーブ。ズームインは連発しない（各シーン最大1回）。
  - 人形は小さく跳ね、首をかしげ・うなずく。食材とメニューカードは「ポン」と少し行き過ぎてから止まる。
- 後処理: 被写界深度（ジオラマ感）→ ブルーム（ペンダント・冷蔵庫の光・AI だけ）→ ビネット → ACES。場面転換は暖色の光のディップ。シャッターの瞬間は白いフラッシュ。
- シリーズ帯: アカウントの帯色 RGB(128,242,255)、黒文字で「親のための AIライフハック」。2段目に場面ごとのトピック。

## デッドゾーン
